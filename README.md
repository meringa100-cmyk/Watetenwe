# Wat Eten We?

AI-kookmaatje: voer in wat je in huis hebt en krijg drie recepten.

## Hosting
Deze app is bedoeld voor Vercel. Zet daar:
- OPENAI_API_KEY = je OpenAI API key
- OPENAI_MODEL = optioneel model naar keuze

Zet de API-key nooit in index.html of in GitHub.

## Structuur
- index.html
- api/recipes.js
- vercel.json
